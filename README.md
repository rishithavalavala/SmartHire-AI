# SmartHire AI – Intelligent Recruitment and Interview Assessment System

## 📌 Project Overview

**SmartHire AI** is an AI-powered recruitment and interview assessment platform designed to simplify the hiring process for recruiters and help candidates evaluate their skills. The system analyzes uploaded resumes, identifies matching and missing skills based on the target job role, generates AI-powered interview questions, and evaluates candidate performance.

The application uses AI to generate role-specific multiple-choice questions and provides detailed assessment results, including scores, correct answers, weak areas, and personalized recommendations. It also includes a recruiter dashboard to review candidate assessment results.

## ✨ Key Features

- **Resume Analysis:** Evaluates candidate resumes based on the selected job role.
- **Skill Matching:** Identifies matching skills and missing skills.
- **AI-Powered Question Generation:** Generates role-specific interview MCQs using the Groq API.
- **Automated Assessment:** Evaluates answers and calculates candidate scores.
- **Performance Analysis:** Displays correct answers, weak areas, and assessment results.
- **Personalized Recommendations:** Suggests areas for improvement based on candidate performance.
- **Recruiter Dashboard:** Helps recruiters review candidate assessment results.

## 🛠️ Technologies Used

- **Python** – Core programming language
- **Flask** – Web application framework
- **Groq API** – AI-powered interview question generation
- **HTML5 & CSS3** – Frontend structure and styling
- **JavaScript** – Frontend interactivity
- **Python Libraries** – Resume processing and application functionality
- **python-dotenv** – Environment variable management

## ⚙️ How It Works

1. The candidate uploads their resume and selects a target job role.
2. The system analyzes the resume and identifies matching and missing skills.
3. AI generates interview questions based on the selected role.
4. The candidate answers the multiple-choice questions.
5. The system calculates the score and identifies weak areas.
6. The candidate receives assessment results and improvement recommendations.
7. Recruiters can use the dashboard to review candidate performance.


## 🎯 Project Objective

The primary objective of SmartHire AI is to make recruitment more efficient by combining resume analysis, AI-generated interview assessments, automated scoring, and candidate performance insights in a single platform.
